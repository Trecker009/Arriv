# Arriv — Bold storefront prototype

Single-file HTML prototype of the Arriv bold-direction website: hero carousel, product cards, collections, product pages (pack sizes, Pairs well with, clinical info sheet), kits, creator videos and the Unsayables.

Open `index.html` in a browser. All images live in `img/`.

Product and campaign images are Pinterest references (tagged REF) used as shoot direction; they are placeholders until the Arriv shoot and must not ship on a live store.
